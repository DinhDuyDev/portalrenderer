# Doom-Styled portal renderer project - portalrenderer

## What it is
A doom-styled portal renderer, with implementation inspired by Ken Silverman's Build engine. 
Project is currently defunct due to problems with line collisions and portal visibility.

## Features
Fully arbitrary geometry - can map out complex spatial geometry.
Functional portal rendering with depth sorting, with reliance on wireframe rendering
3D movement.

## In need
Fully functional depth sorting for all cases.
Perspective-correct texture mapping.
